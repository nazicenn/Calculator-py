#  Getting Started

## Requirements

* Python 3.10+
* Tkinter (included with Python)

---

## Run Project

```bash
git clone https://github.com/USERNAME/calculator.git

cd calculator

python -m app.main
```

---

#  Build EXE

```bash
pip install pyinstaller

pyinstaller --onefile --windowed --name "Calculator" app/main.py
```

Generated executable:

```text
dist/Calculator.exe
```
